----------------------------------------------------------------------
1) Reach the dashboard
----------------------------------------------------------------------
{{- if .Values.ingress.enabled }}
Ingress is enabled. Open:

  http{{ if .Values.ingress.tls.enabled }}s{{ end }}://{{ .Values.ingress.host }}/

{{- if .Values.ingress.ingestHost }}
The ingest API is at:

  http{{ if .Values.ingress.tls.enabled }}s{{ end }}://{{ .Values.ingress.ingestHost }}/v1/events
{{- else }}
The ingest API is exposed at:

  http{{ if .Values.ingress.tls.enabled }}s{{ end }}://{{ .Values.ingress.host }}/v1/events
{{- end }}
{{- else }}
No ingress configured. Port-forward the dashboard:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "costobs.fullname" . }}-dashboard {{ .Values.dashboard.service.port }}:{{ .Values.dashboard.service.port }}
  # open http://localhost:{{ .Values.dashboard.service.port }}

And the ingest API (to point an SDK at it):

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "costobs.fullname" . }}-ingest {{ .Values.ingest.service.port }}:{{ .Values.ingest.service.port }}
  # COSTOBS_INGEST_URL=http://localhost:{{ .Values.ingest.service.port }}
{{- end }}

3) Dev seed / API key
----------------------------------------------------------------------
{{- if .Values.devSeed.enabled }}
devSeed is ENABLED. Org "{{ .Values.devSeed.orgSlug }}" and a dev API key were
seeded. Retrieve the key:

{{- if .Values.devSeed.existingSecret }}
  kubectl -n {{ .Release.Namespace }} get secret {{ .Values.devSeed.existingSecret }} -o jsonpath='{.data.dev-api-key}' | base64 -d; echo
{{- else }}
  kubectl -n {{ .Release.Namespace }} get secret {{ include "costobs.secretName" . }} -o jsonpath='{.data.dev-api-key}' | base64 -d; echo
{{- end }}

  ** WARNING: devSeed is for demos only. Disable it (devSeed.enabled=false)
     and rotate the key for any real deployment. **
{{- else }}
devSeed is disabled (correct for production). Create an org + API key through
the dashboard / admin flow, then point your SDK at the ingest URL with that key.
{{- end }}
